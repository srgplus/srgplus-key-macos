# SRG+ Key for Mac

The Mac app of [SRG+ Key](https://srgplus.app) for download outside the App Store: Developer ID signed and notarized by
Apple, updating itself with Sparkle.

- **Download:** https://github.com/srgplus/srgplus-key-macos/releases/latest/download/SRG-Plus-Key.dmg
- **Update feed:** `appcast.xml`, served by GitHub Pages at https://srgplus.github.io/srgplus-key-macos/appcast.xml

The app's code lives in a private repository; this one holds only the releases and the feed. Each release is added by the
app's `apps/apple/scripts/mac-dmg.sh --publish`, through a pull request here.
